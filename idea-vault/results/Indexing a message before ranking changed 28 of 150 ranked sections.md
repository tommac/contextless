Real calls used to rank with the new message already in the index, so its words shifted the statistics of its own ranking, while the probe commands ranked without it. A message now enters the index after it is answered, and real calls build the same packet as cx packet and cx probe. Before the fix 28 of 150 ranked sections differed between the two paths, so probe numbers did not describe exactly what real calls sent.
