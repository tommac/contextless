Two peer-reviewed studies bound how well threads can be rebuilt from chat. A fine-tuned model predicting reply links reached Shen F 0.90 on developer chats outside its training domain, while in another study a fine-tuned model reached 74.4 percent link F1 but only 45.3 percent F1 for perfectly matched conversations. This is a caution from chat disentanglement, not a test of this project: threads that are inferred need confidence handling.
