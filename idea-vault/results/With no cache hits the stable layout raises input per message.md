The spine and epoch steps make each brief longer, so if no prefix is ever served from cache the input per message would rise from 14,381 to 15,296, from 18,741 to 19,910 and from 25,483 to 28,442 on the three real conversations. The design document gives both ends, every call a hit and no call a hit, and does not state the hit rate at which the new layout costs the same as the old one. That downside is why the two steps stay off until a live test shows hits.
