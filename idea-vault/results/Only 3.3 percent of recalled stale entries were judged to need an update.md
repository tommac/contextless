In STALE's write-time diagnostic, the entries a memory system recalled included the old evidence in 60.5 percent of cases, but only 3.3 percent of those old entries were judged as needing an update. Retrieval found the stale note and the system still did not revise it. Staleness is therefore a problem of deciding at write time as much as of retrieving.
