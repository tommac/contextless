MemTxn stores append-only versions with a pointer map to the active version and a recovery journal. A lexical gate admits a write only if the cited evidence appears in the source and the value tokens appear in order, with no verifier model call. The notes take from it a split that suits a deterministic engine, in which a model may propose a fact while admission and visibility are decided by code. The report lists it as prior art for lexical evidence gates, and its audit used template-made corruptions only.
