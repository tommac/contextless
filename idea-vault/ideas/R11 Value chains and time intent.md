The hypothesis is that high-precision chains built from exact value and key matches, with a rule-based router for current, previous and change questions, cut stale exposure without hiding history. The chains are built in code from the value index and favour precision, because in the nearest study false merges removed current values. It is falsified if false merges remove any meaningful share of current values, or if the plain newest-first lane does as well.
