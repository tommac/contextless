Explicit links help when an answer must be put together from units that do not share words, and they add nothing or hurt on single-fact lookup and procedural logs. In a peer-reviewed comparison the value of an index tracked the structural rate, the share of questions no single retrieved unit can answer. For this project that means measuring the local structural rate before building any link graph, and treating each link as a candidate to be scored.
