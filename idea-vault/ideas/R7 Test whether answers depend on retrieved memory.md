The hypothesis is that a sizable share of correct answers do not depend on the cited atom, and that value swaps expose this where citations do not. On items answered correctly, the question is asked again with the top or cited atom removed, with only that atom, and with the answer value changed in a scratch copy of the workspace. It is falsified if nearly all answers follow the swap and fail on removal in every arm, because a protocol that cannot tell arms apart is not a contribution.
